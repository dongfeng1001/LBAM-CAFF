# LBAM-CAFF
The code for TVC 2026 paper "Context-Guided Lightweight Network for Robust Outdoor Fire and Smoke Detection".

This is an improved model LBAM-CAFF based on YOLOv8n for fire and smoke target detection.

Code:
You can get the official YOLOv8 code at https://github.com/ultralytics/ultralytics, and then add our improvement code to the project.
We have released all the improved code, and the code in project format is still being organized.

Datasets download：
In our work, we can open-source the D-Fire dataset, but the Fire-Smoke-DET dataset is currently not available for public download. 
The D-Fire dataset is a benchmark resource developed by the team at Gaia Solutions on Demand in Brazil, provides open-access images of fire and smoke captured in real-world industrial settings. 

The corresponding reference is as follows:
de Venancio P V A B, Lisboa A C, Barbosa A V. An automatic fire detection system based on deep convolutional neural networks for low-power, resource-constrained devices[J]. Neural Computing and Applications, 2022, 34(18): 15349-15368.

The D-Fire dataset is available at: https://pan.baidu.com/s/1JvmAE35z-WVIrAR9zdkjqQ
